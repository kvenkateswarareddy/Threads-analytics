# Time log (exam template)

The exam asks for a sheet with the columns **Title | Problem breakdown | Usage time (one block every 30 minutes)**.
The Google Sheet link in the brief is not something the AI could open or edit, so this is a template. **The rows below are a DRAFT split of the work, not real timings. Replace them with the time you actually spent**, one 30-minute block per row segment.

| Title | Problem breakdown | Usage time (30-min blocks) |
|---|---|---|
| Understand the brief | Read requirements, scoring table and compliance rules; decide mock-data strategy | 1 block |
| Project setup | Next.js scaffold, Supabase project, env vars | 1 block |
| Database + auth | Run migration, RLS check, sign-up / sign-in / magic link | 2 blocks |
| Data pipeline | Mock generator, cleaning, time-zone normalisation, text features | 2 blocks |
| Analysis | Averages, top 5, time distribution, length correlation, keywords, post types | 2 blocks |
| NLP group analysis | Three groups, feature method, 3-5 sample posts per group, reasons | 2 blocks |
| Report UI | Dashboard, charts, tables, export | 2 blocks |
| Tests + fixes | Unit tests, bug fixes, build | 1 block |
| Docs + deploy | README, AI_LOG, GitHub push, Vercel deploy | 1 block |
