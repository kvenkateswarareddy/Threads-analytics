## 4. AI errors that were caught and corrected

1. **Dedup bug (caught in review while testing):** when a later duplicate had higher engagement it replaced the stored copy under only one lookup key, leaving the stale copy under the other key, which could re-appear in the output. Fixed by re-pointing every key that referenced the old object.
2. **Zero-filling distorted the analysis (caught by reading the sample report):** missing like counts were set to 0, so a post with a missing value showed up as a "0 likes" sample in the *low* group. Changed to median imputation and added a test.
3. **Environment:** when `npm install` returned 403, the AI did not try to bypass the restriction; it switched to Bun/tsc for verifying the dependency-free library code and reported the limitation.

No hallucinated libraries or APIs were found in the verified parts; the unverified parts (Supabase SSR cookie API, recharts props, Threads API fields) follow the documented APIs as the AI remembers them and should be checked by the first build.
